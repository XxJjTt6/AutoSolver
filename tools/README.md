# 开发工具

`tools/` 提供调试、演示和交付阶段使用的辅助脚本，不参与正式比赛求解入口的热路径。

| 工具 | 用途 |
|---|---|
| `agent_trace_demo.py` | 解析样例、运行策略并输出 Agent 决策轨迹摘要。 |
| `llm_evolution_demo.py` | 演示可选的策略生成与演化流程。 |
| `render_lineage.py` | 将策略来源和演化关系整理为可阅读结果。 |
| `make_submission.py` | 执行验证门并构建带哈希清单的本地交付目录。 |

打包脚本会运行编译、测试和基准检查。当前仓库为精简后的公开最终版本，若脚本清单引用未公开归档材料，应先按实际交付范围调整清单再执行。
