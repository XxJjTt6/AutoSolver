# AutoSolver Agent

`autosolver_agent/` 在核心求解器之上提供自主策略探索、统一评估、结果记忆和安全演化能力。

## 工作循环

1. 识别任务规模、骑手稀缺度、接单意愿和组合任务特征。
2. 选择与场景匹配的候选策略，并为每个策略分配运行时间片。
3. 使用统一 Critic 检查合法性和本地目标改进。
4. 接受更优结果，拒绝无效结果，并记录原因。
5. 将场景、策略和结果反馈写入演化记忆，供后续轮次召回。

## 主要文件

| 文件 | 作用 |
|---|---|
| `system.py` | Agent 能力定义、策略编排、Critic 评估和事件轨迹。 |
| `evolution.py` | 策略生成、质量门、安全试跑和演化状态管理。 |
| `llm_generator.py` | 可选的大模型策略生成接口；未配置时保持确定性回退。 |

实验策略不会直接覆盖根目录的正式比赛求解器。任何候选都必须经过安全检查、限时执行和质量门后才能进入演示链路。
