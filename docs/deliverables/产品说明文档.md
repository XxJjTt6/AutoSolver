# AutoSolver 产品说明文档

## 1. 产品定位

AutoSolver 是一套外卖配送智能调度工作台。它把订单释放、骑手移动、路线选择、策略评分和经验复用放到同一条全天时间轴上，让评委既能看到最终派单，也能看到系统为什么这样派。

当前 v7 的重点不是单独展示一张结果表，而是用双屏对比验证调度效果：左侧运行最近距离贪心基线，右侧运行 AutoSolver Agent，两侧使用同一批订单、同一批骑手和同一推演时钟。

## 2. 要解决的问题

最近距离并不总等于整体最优。高峰、拥堵、运力紧张和顺路合单同时出现时，只看当前取餐距离，容易把短期方便变成后续排队、超时或运力失衡。

AutoSolver 会综合考虑：

- 订单承诺时间和超时风险；
- 骑手当前位置、负载和预计空闲时间；
- 取餐、送达和顺路合单路线；
- 当前时段的需求压力和运力缺口；
- 历史相似场景中验证过的调度经验。

## 3. 五个核心页面

| 页面 | 评委能看到什么 |
|---|---|
| 双屏对比 | 同一订单在两套算法下的骑手、路线和结果；等待时间、配送成本、超时单和趋势随时间分化。 |
| 决策过程 | 一轮派单的触发原因、输入订单、候选骑手、可行性过滤、策略评分、采纳方案和放弃方案。 |
| 长期记忆 | 冷启动后的经验沉淀、相似场景召回、结果回写、学习曲线和跨场景策略迁移。 |
| 订单池 | 截至当前推演时刻已经下单的订单、风险等级、派单状态以及基线/我方结果。 |
| 骑手运力 | 当前在线骑手、班次、位置、负载、任务链、区域覆盖和预计空闲时间。 |

## 4. 双屏对比为什么可信

两侧不是两段独立录制的结果，而是同一个全天仿真合同的两次运行：

| 对照项 | 基线 | AutoSolver Agent |
|---|---|---|
| 订单流 | 相同 | 相同 |
| 时间轴 | 相同 | 相同 |
| 骑手初始状态 | 相同 | 相同 |
| 调度策略 | 最近距离贪心 | 时效、成本、风险和运力综合决策 |
| 页面显示 | 左屏 | 右屏 |

页面支持暂停、继续、倍速、时间轴跳转和同单锁定。选择同一笔订单后，两张地图会同步高亮，便于直接核对两套算法的处理差异。

## 5. 决策可追溯

每轮决策按照固定顺序展开：

1. 判断为什么需要重新调度。
2. 确认本轮已经释放的订单。
3. 收集当前可用骑手。
4. 过滤班次、容量和时间窗不满足的候选。
5. 对可行方案比较时效、成本和超时风险。
6. 输出派单动作，并记录采纳与放弃原因。

策略池会比较最近距离、成本优先、风险均衡、匹配、稀疏覆盖、最小费用流和 AutoSolver 等候选。页面展示的是候选比较结果，不是事后补写的一句解释。

## 6. 长期记忆

长期记忆用于把一次派单的结果转化为后续可复用的经验：

- Read：根据当前时段、天气、区域压力和运力状态召回相似经验。
- Decide：将召回结果作为策略选择和风险判断的参考。
- Write：把本轮结果、收益和失败原因回写到经验库。
- Reflection：把多轮经验整理为全局策略、骑手画像、商圈画像和订单风险画像。

记忆页同时展示召回链路和效果反馈，便于判断一条经验何时被使用、使用后是否有效。

## 7. 因果化订单和运力

订单只会在真实下单时刻之后进入订单池，页面不会提前展示未来订单。骑手状态也随班次和推演时钟变化。

演示中可以临时新增订单或骑手。新增实体只影响当前推演时刻之后的决策，已经发生的派单不会被倒改；后台重算完成后，双屏对比、订单池和骑手运力会使用同一份更新结果。

## 8. 使用方式

### 在线演示

[https://xxjjtt6.github.io/AI-Hackahton_meituan/](https://xxjjtt6.github.io/AI-Hackahton_meituan/)

### 本地演示

Python 3.10 或更高版本即可运行：

```bash
python3 web_agent_demo/server_v7.py --host 127.0.0.1 --port 8765
```

浏览器打开 `http://127.0.0.1:8765`。

### 推荐演示顺序

1. 双屏对比：先证明两套算法的差异。
2. 决策过程：解释差异从哪里产生。
3. 长期记忆：说明系统如何复用经验。
4. 订单池和骑手运力：核对决策输入。

## 9. 产品边界

- `web_agent_demo/server_v7.py` 是当前本地演示入口。
- `solver.py` 是正式比赛求解入口，两者用途不同。
- `server.py`、`server_v2.py` 至 `server_v6.py` 仅作为历史版本保留。
- 页面中的时间、成本、超时和趋势指标来自当前演示数据，用于解释和对照，不替代官方评测结果。
- 正式成绩以比赛方评测记录为准。
