# AutoSolver 作品简介

AutoSolver 是面向外卖配送场景的智能调度系统。当前 v9 演示把同一批订单放到同一条时间轴上，左侧运行最近距离贪心基线，右侧运行 AutoSolver Agent，通过双屏对比直接展示路线、等待时间、配送成本和超时情况的差异。

系统不仅给出派单结果，还提供决策过程和长期记忆页面。评委可以查看每轮为什么触发、哪些候选被过滤、哪套方案被采纳，以及历史经验如何被召回、回写并用于后续相似场景；订单池和骑手运力页面用于核对当时真实可见的输入状态。

本地演示入口是 `web_agent_demo/server_v9.py`。页面中的对比指标用于解释系统行为，不替代比赛官方评测结果；正式比赛求解入口仍为 `solver.py`。
