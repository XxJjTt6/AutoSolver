# 第一块 · 让评委看得懂：可理解性与引导式叙事

## 16.1 五条核心原则（假设评委=无运筹背景的产品经理）

| # | 原则 | 一句话 | 为什么需要 |
|---|---|---|---|
| P1 | 引导式叙事 > 仪表盘 | 默认进 Guided Mode，一个大"下一步"带着走 | 仪表盘要评委自己组织信息；故事线替他组织好 |
| P2 | 一次只讲一件事 | 每步**只引入 1 个新概念或 1 个新数字**，第二个就拆步 | 导师："信息密度低、看不出区别" |
| P3 | 全程人话 + 方向锚 | 界面无学术词；每个数字带"↑/↓ 越X越好" | 评委不知道哪个方向是赢 |
| P4 | 巨大对比 + 单一结论 | 每屏顶部一张判决卡，只给一个主数字 + 一句谁赢 | 导师："结果前置、一眼看到" |
| P5 | "你正在看什么"常驻 | 屏幕固定位置永远有一行字幕说明当前画面 | 导师："每页缺一句话 summary" |

## 16.2 方向锚 + 颜色约定（修 P0：数字缺方向锚 / 颜色非自解释）

**每个关键数字强制带方向箭头 + 一字判定，首次出现给"越X越好"：**

| 数字 | 屏幕写法（强制） |
|---|---|
| 每单成本 | `每单成本 654 ↓越低越好（原来 2097）` |
| 准时率 | `准时率 92% ↑越高越好` |
| 降幅 | `省了 68.7% ✅`（**消灭负号**，−68.7% 对产品评委是负面信号） |
| 识别稳定性 | 用"10 次认对几次"代替百分比（见 16.13） |

**颜色约定必须在 onboarding/常驻图例里显式写死一次**（不能假设评委自己悟）：
`🟩 绿 = 我们的方案（目标是赢） 🟧 橙 = 普通方案（参照） 🔵 蓝 = 我们的方案·不带记忆（对照）`

## 16.3 渐进披露三态 + 两条硬规则

每个面板三态：**folded(一句话) / summary(默认) / expanded(点开)**。

**硬规则 1**：同屏 expanded 面板 ≤ 1 个；推进到新步自动收回上一个。
**硬规则 2**：学术词只能出现在 expanded 层、且必带括号人话。folded/summary 层永远是人话。

## 16.4 禁词表（修 P1：术语漏出。下列词严禁出现在界面文字与现场旁白）

| 禁用原词 | 界面/旁白只能说 |
|---|---|
| 滚动时域 / receding horizon | "单子一波波来，来一波就重新排一次，已派出的不动" |
| regime / 场景画像 / case_profile | "当前是什么状况"；且 large→**大单量场景**、small→**小单量平峰**、low-willingness→**骑手不愿接**、scarce→**运力紧张** |
| 泳道 | "三条线" |
| lineage / 血缘 | "这个策略的来历" |
| best-so-far | "目前找到的最好方案" |
| 暖启动 / 冷启动 | 全场统一："带记忆 / 不带记忆"（图例同步） |
| 本地确定性口径 | "同一套题、原方法 vs 我们方法的同台对比，跑多少次都一样（可复现）" |

## 16.6 5 秒 onboarding +常驻图例（修 P0：颜色约定须显式）

进页面自动播一次（可关、可重看），三步约 5 秒：
```
第1秒：判决卡呼吸高亮 + 箭头「① 谁赢，看这里」
第3秒：双屏左右各打标签「② 普通方案」「② 我们的方案」
第5秒：底部曲线滑入 + 箭头「③ 越往右，绿线越优」→「开始演示 ▶」
```
**常驻图例条**（顶部固定，全程不消失，同时承担 P5 与演示角标合规）：
`🟩我们的方案 🟧普通方案 🔵我们的(不带记忆) ✨流动线=当前采纳路线 🏷演示数据=仿真合成 | 🎬离线真实记录·回放`
